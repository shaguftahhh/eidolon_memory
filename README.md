## 🌑 About the Project

**EIDOLON** (The Last Message — An Offline Memory Ghost) is an interactive AI experience that explores how forgotten memories can be preserved, rediscovered, and connected through technology.

Photographs fade into forgotten folders. Diary fragments lose their context. Voice recordings remain unheard for years. EIDOLON imagines a different future — one where these fragments form a living digital archive.

Instead of pretending to be someone from the past, EIDOLON acts as a **spectral memory archivist**, helping people explore the stories and connections hidden within preserved memories.

The result is an atmospheric experience that feels like discovering a ghost inside a machine.

## 🧠 Why Open-Weight AI?

EIDOLON explores how open-weight AI can make personal memory tools more private, adaptable, and independent of cloud services.

### 🔐 Privacy by design

Personal memories can be deeply sensitive. A local-first architecture aims to keep personal content on the user's device rather than automatically sending it to an external server.

### 📴 Offline potential

With a compatible locally running model and the necessary dependencies installed, the experience can work without a permanent internet connection.

### 🔄 Model flexibility

Using an open-weight model such as **Gemma 2** creates opportunities to experiment with different models and customize the AI experience.

### 🌱 Open innovation

Developers can explore, adapt, and extend the architecture rather than relying entirely on a single closed AI service.

> **Your memories shouldn't need permission from a server you don't own.**

*Note: Offline inference and local-only data handling depend on the actual implementation. Verify these capabilities before claiming that all processing is offline.*

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) — a compatible version
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/shaguftahhh/Edilon_memory.git
```

Enter the project directory:

```bash
cd Edilon_memory
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

**Model setup:** If Gemma 2 inference is not already configured in the application, follow the model runtime and configuration instructions added to the project before expecting AI responses. The interface alone does not guarantee that local inference is working.

## 🎃 Ghost in the Machine

EIDOLON interprets the *Ghost in the Machine* theme through a simple idea:

**The ghost is not the AI. The ghost is the memory.**

Rather than relying on conventional horror, the experience explores the uncanny feeling of discovering something forgotten that still exists inside a machine.

It also draws inspiration from the spirit of remembrance associated with Día de los Muertos, where photographs, stories, and meaningful objects help people honor the past.

EIDOLON is designed around preserving and exploring memories, not claiming to contact the dead or authentically recreate a person.
